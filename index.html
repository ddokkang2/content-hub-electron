같은 사이트를 다른 계정으로 열면 별도 pane으로 뜹니다.

왜 webview인가?

iframe이 아니라 Electron webview라서 각 사이트의 frame-ancestors 차단을 받지 않고 앱 안에 그대로 뜹니다.

비밀번호 저장 없음 · API 없음.

계정마다 webview partition이 분리되어 로그인이 섞이지 않습니다.

사이트 관리

사이트를 추가·수정·제거할 수 있습니다. 최소 1개는 남겨야 합니다. 변경 사항은 앱에 저장되어 재시작해도 유지됩니다. 같은 사이트를 다른 계정으로 열려면 행마다 계정으로 열기를 쓰세요.

    계정 관리

    계정마다 webview partition이 분리됩니다 (예: YouTube 개인 / YouTube 업무를 동시에 로그인). 최소 1개 계정이 남아야 하며, 기본 계정은 삭제할 수 없습니다. 계정을 지우면 그 계정의 pane은 기본 계정으로 옮겨지거나, 같은 사이트의 기본 pane이 이미 있으면 닫힙니다.

      단축키

      Ctrl / Cmd + 1 ~ 9사이드바 순서대로 pane 포커스 전환
      Ctrl / Cmd + B사이드바 접기 / 펼치기
      Ctrl / Cmd + R 또는 F5포커스 pane만 새로고침 (브라우저 기본 새로고침 대신)
      Ctrl / Cmd + K빠른 전환 팝업 열기 / 닫기
      Esc열린 모달 / 팝업 닫기
      ↑ / ↓ + Enter빠른 전환에서 이동 / 선택

      입력 필드에 포커스가 있을 때는 단축키가 동작하지 않습니다 (Esc 제외). 빠른 전환 입력 중에는 Ctrl/Cmd+K를 눌러도 팝업이 중복으로 열리지 않습니다.

      북마크 스냅샷

      현재 모든 pane의 URL + 포커스 + 뷰 + 그리드 설정을 스냅샷으로 저장합니다. 복원하면 각 pane이 저장된 URL로 다시 로드됩니다.

          ↑ / ↓ 이동 · Enter 선택 · Esc 닫기
